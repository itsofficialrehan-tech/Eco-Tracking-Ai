# 🌍 EcoTrack AI

> Track. Understand. Reduce. Build a Sustainable Future.

EcoTrack AI is a next-generation carbon footprint awareness platform designed to help individuals measure, analyze, and reduce their environmental impact through intelligent insights, sustainability scoring, goal tracking, and AI-powered recommendations.

Built with a strong focus on performance, accessibility, security, and user experience, EcoTrack AI transforms complex environmental data into actionable steps that encourage sustainable living.

---

## ✨ Features

### 🤖 AI Sustainability Coach

Receive personalized recommendations based on your lifestyle and carbon footprint data.

### 📊 Smart Carbon Calculator

Calculate emissions from:

* Transportation
* Electricity Usage
* Food Consumption
* Shopping Habits

### 🎯 Goal Tracking

Set sustainability goals and monitor progress over time.

### 🏆 Sustainability Score

Get a score between 0-100 based on your environmental impact.

### 📈 Interactive Dashboard

Visualize trends using:

* Line Charts
* Pie Charts
* Monthly Reports
* Progress Analytics

### 📄 Export Reports

Generate downloadable PDF and CSV reports.

### 🌙 Dark Mode

Modern UI with full dark mode support.

### 📱 Fully Responsive

Optimized for:

* Mobile
* Tablet
* Desktop
